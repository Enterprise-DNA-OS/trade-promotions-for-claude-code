---
description: The Monday trade review.
---

Run: `npm run trade -- weekly-review`

Run /attention first, then this. Write five lines: what is in store in the next six weeks and anything not agreed, claims and deductions to clear with the oldest first, open accruals, the checks that failed (grocery code first), and what the last promotions returned. Use /draft-review if the operator wants it written up.

Options use --name=value. Add --json for structured output. Money is GST exclusive, in each customer's currency. Drafts go to drafts/ and are never sent from here. Nothing here pays, invoices or emails a retailer.
